# 999 FOUNDERS · 사업 소개 랜딩

999 파운더스(프랜차이즈 컨설턴트 창업 플랫폼)의 **사업 소개** 정적 랜딩페이지.
수당/보상 구조는 다루지 않고, "999 파운더스가 어떤 사업인지"만 담백하게 소개한다.

- 상단 인트로: 기존 999 홍보영상 `public/promo.mp4`
- 4대 기둥: 검증된 아이템 · 운영지원 · 체계적 교육 · 정직한 관리
- 컨셉: "창업의 99.9%는 우리가 준비, 0.1%만 당신이" / 순도 99.9
- 실 서비스 플랫폼: https://www.999founders.com

## 구성
- `index.html` — 단일 파일 (CSS/JS 내장), 다크 잉크 + 골드 톤, Noto Serif KR + Pretendard
- `public/promo.mp4` — 인트로 영상
- `public/img/*.webp` — 섹션 이미지 (Replicate Flux 실사)
